# Swedish Job Market Analysis

A data pipeline that collects job listings from the Swedish job market and creates analytics dashboard for analyzing skill demand trends in the Swedish data science job market using the JobTech API.

## Tech Stack

- Python
- Requests
- DuckDB
- Pandas
- dbt
- Streamlit
- Plotly

## Goals

- Collect Swedish job listings
- Analyze demand for data science skills
- Visualize trends in an interactive dashboard
